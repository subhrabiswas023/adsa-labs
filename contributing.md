# Contributing to ADSA Labs

Thank you for contributing to ADSA Labs!

This repository is intended for implementing, testing, and analysing
Advanced Data Structures and Algorithms while
following idiomatic software engineering practices.

## What Can You Contribute?

Contributions can include:

- Implementing an unimplemented problem
- Fixing bugs in an existing implementation
- Adding missing or better test cases
- Improving test coverage
- Providing alternative algorithmic implementations
- Improving documentation
- Improving the build system or development tooling
- Reporting bugs or suggesting general improvements

Alternative implementations are particularly welcome when they provide
a meaningful difference in algorithmic approach, complexity, or design.
